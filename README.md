# 賽馬分析工具 (Horse Racing Tool)

個人賽馬數據分析工具 — 「紀律＋數據」，目標係長期 ROI 跑贏市場，而唔係估中邊隻馬贏。

## 用法

經 GitHub Pages 開啟（手機／電腦瀏覽器都得），所有數據只存於你部裝置嘅瀏覽器 localStorage，唔會上載。

### 四個分頁

- **賽事排位**：按賽期／場次睇排位表，系統標示「有值／偏熱」，並自動生成推介理由
- **馬匹往績**：馬匹 profile、速度評分、往績表
- **Value 板**：只顯示市場賠率高過應有價值（fair odds）嘅馬，連半 Kelly 建議注碼
- **記賬・資金**：投注記錄、ROI 統計、注碼計算機（Fractional Kelly）、備份匯出／匯入

### 匯入數據

- **排位表 CSV**欄位：`會議chip,會議標題,會議副題,場次,場次資訊,檔位,馬號,馬名,評分,速度評分,近績,賠率,Fair,信心`
- **馬匹往績 CSV**欄位：`馬名,基本資料,騎練組合,速度評分,日期,馬場,途程,場地,名次,時間,負磅,騎師`
- App 入面有「下載範本」掣

### 備份

換手機／清瀏覽器數據前，喺「記賬・資金」分頁㩒「匯出備份 (JSON)」。
